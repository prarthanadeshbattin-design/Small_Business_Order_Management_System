# Job Application Tracker

## Project Description

Job Application Tracker is a Python application designed to help users organise and manage their job applications in one place.

## Features

- Add new job applications.
- View all saved applications.
- Update application details.
- Delete applications.
- Search applications by company or job title.
- Track application status.
- View application statistics.
- Save application data for future use.

## Technologies Used

- Python
- Git
- GitHub
- Tkinter (for the graphical user interface)
- JSON (for storing application data)

## How to Run

The application will be available in two versions:

1. Command-Line Interface (CLI)
2. Graphical User Interface (GUI)
